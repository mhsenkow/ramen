# Inspiration

## `oneill-cylinder-interior.png`

Classic O'Neill-cylinder interior concept art — the visual target for RAMA's
"whole drum is one system" read:

- Continuous land wrapping overhead (not a skybox)
- Lakes and rivers sitting in the terrain, not floating sheets
- Soft mid-altitude clouds that obscure far detail naturally
- High-detail near ground → hazed far wall
- Axis light as the sun

Use this when judging far-field coverage, water, biome paint, and god-mode
survey views. Not a style to copy pixel-for-pixel — a composition / intent check.
